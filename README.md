# Sabe Mais: Aprender Sem Limites

Crie um site completo chamado Sabe Mais, uma plataforma brasileira de estudos voltada principalmente para estudantes do ensino fundamental e médio.

IDENTIDADE DO SITE

Nome: Sabe Mais

Slogan:
"Aprenda mais. Entenda melhor. Vá mais longe."

O site deve ter aparência moderna, jovem, organizada e profissional. Deve transmitir a sensação de uma plataforma brasileira de estudos fácil de usar.

Evite um visual infantil. Use uma interface que funcione bem tanto para estudantes mais novos quanto para adolescentes.

FUNCIONALIDADE

Não criar apenas uma interface visual.

As ferramentas precisam funcionar de verdade no navegador.

Utilizar localStorage quando necessário para guardar:

Tarefas

Pontuação

Progresso

Conquistas

Preferências

O site deve funcionar inicialmente sem banco de dados e sem servidor.

EXPERIÊNCIA DO USUÁRIO

Quando o usuário entrar no Sabe Mais, deve conseguir entender o funcionamento do site rapidamente.

A navegação deve ser simples.

O estudante deve conseguir chegar a uma ferramenta ou matéria em poucos cliques.

Adicionar pequenas animações ao passar o mouse sobre cards e botões.

Evitar excesso de elementos na tela.

O resultado final deve parecer uma plataforma de estudos real e profissional, e não apenas um projeto escolar.
